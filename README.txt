EGG SALES SYSTEM
=================

Technology: PHP + MySQL + HTML/CSS/JavaScript

INSTALLATION (XAMPP)
1. Copy the "egg-sales-system" folder into C:\xampp\htdocs\
2. Start Apache and MySQL in XAMPP.
3. Open http://localhost/phpmyadmin
4. Import database.sql
5. Open http://localhost/egg-sales-system/

LOGIN
Username: admin
Password: admin123

PAYMENT METHODS
Only:
- Cash
- Mobile Money
- Bank

MODULES INCLUDED
- Login / Logout
- Dashboard
- Products
- Sales
- Printable Receipt
- Inventory
- Customers
- Suppliers
- Purchases
- Expenses
- Reports

IMPORTANT
Change the default admin password before using the system in production.
The current MVP uses SHA-256 for the seeded demo password. For a production deployment, migrate authentication to password_hash/password_verify.
